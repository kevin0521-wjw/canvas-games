## 为什么值得单独立一档

`starlane-v2`（星轨防线 v2 · 缝合版）是它的后继者，但两者并不是「同一条线上的两个分支」：
初版是一个 5503 行、800×600、带完整排行榜与自研参数系统的作品，
而 v2 是把另外三款游戏的机制往太空射击骨架上缝的实验。
把初版留在档案里，才看得出 v2 相对「起点」到底走了多远 —— 而不是只看到一个孤立的成品。

另外，v2 这轮新加的 **AI 接管** 与 **二倍速**，其实**初版就有了**：

- `CFG.SPEED = { NORMAL: 1, FAST: 2, TAG: '×2' }`，快捷键 `F`
- `AutoPilot`：AI 接管整局，快捷键 `I`；实现上给游戏塞了一个「虚拟手柄」，
  接口与真实 `Input` 完全同形，所以 AI 的速度上限和碰撞判定与真人一致，不能靠手速作弊

这轮把它们搬回 v2 时，做法上有一处**刻意的不同**：

| | 初版 | v2 |
| --- | --- | --- |
| 二倍速实现 | `step = dt * timeScale`（把时间步乘 2） | 固定步长 + 时间累加器，2× 时每帧跑两次 `update(1)` |
| 隐患 | dt 翻倍会让快弹一步跨过判定圆（弹速 4.1px/帧 vs 判定半径 ≈10.5px） | 物理步长恒为 1，判定精度与倍速无关 |

这不是说初版写错了 —— 它有自己的 `MAX_DT` 上限兜着，实际运行未必出问题。
但 v2 既然要重写一遍，就顺手把这类「倍速影响判定」的可能性彻底掐掉了。

## 这份存档的验证

`verify/smoke.js` 会在真实浏览器里把它跑起来（headless Edge + CDP），验三件事：

1. 文件完整、能被浏览器真正执行（不是把 HTML 存坏了）
2. 两个招牌功能还在：AI 自动接管、二倍速
3. 输入 → 主循环 → 绘制这条基本链路是通的

它会和另外四款一起出现在 `_logs/space-line-v1.log`，并被 `_snapshot.js` 一起留档，
所以「这一版当年长这样、当时验过没有」两件事都有据可查。
